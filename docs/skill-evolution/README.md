# Selected Skill Evolution Summaries

This directory contains reviewed summaries of adopted changes and important maintenance decisions. It is a selected publication, not a complete activity log. Detailed discussions, experiments and private recovery material remain in the ignored local archive. Ordinary pushes do not back up that archive.

See the [history policy](../agents/evolution-history.md) for selection and retention rules. Each summary states the problem, change, evidence and limits. Sequence numbers retain their local identity, so gaps are expected.

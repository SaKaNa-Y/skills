# Assess the scope of a single PR

A request to assess a PR can arrive without its original problem record. Assess now follows the project records and linked audits before recommending delivery scope. It uses the existing grouping and scope comparison methods for both related records and observations made during review. Evidence access limits still apply.

The candidate recovered the originating item and the old recent-items report on the first turn. It kept the confirmed archive caption defect separate under the original promise and required a correction when the release promised exact titles on archive reopen. The original method also found the sibling and separated the archive defect on the matched control. These trials support the routing in the tested cases. Comparative improvement remains unproven.

# Just owns versioned usage coverage

Date: 2026-10-23. Source change; separate installed copies are excluded.

A successful usage audit could end with coverage only in the conversation. Later tasks then lacked a reliable account of the exercised scope and version. Just now owns reading, saving and checking coverage even when no finding or triage workflow exists.

Each target repository has its own coverage index and linked batch evidence. The index groups stable user outcomes and keeps their modes separate. Batches identify the source and artifact actually executed. Reusing evidence adds an applicability judgment without changing its original execution date or commit. Narrow reruns preserve other modes and earlier failures.

The shared contract also covers historical imports, concurrent index updates, blocked persistence and independent audits. A closed history gate permits provisional capture but defers index reads and reconciliation. Coverage does not create a problem record or increase problem counts.

Independent standalone execution saved a no-finding audit and read prior coverage before a later task. Further trials exercised artifact/source mismatch, historical import, relevant revalidation, narrower follow-ups, blocked persistence and a blind pause. Tool events and saved files were inspected; links and recovery inventories passed. Concurrent writers and affirmative record-commit behavior were reviewed, not executed. The tests use a small local CLI; they do not establish universal agent reliability or behavior on large product audits. Baseline source is commit `1e33abceb2880ab1ff904b66d3cbd67156d263d1`. The commit introducing this entry preserves the source delta from that baseline; exact affected-file recovery and execution evidence remain in the private archive under repository policy. A subsequent writing review clarified per-boundary reuse judgments, included checkpoint outcomes in phase completion, split the checkpoint/continuation/pause instructions and completed the shared reference trigger. These refinements received instruction and structural checks; the earlier execution trials tested the preceding candidate.

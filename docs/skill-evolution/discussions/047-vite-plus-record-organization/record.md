# Browse and assess working records by category

Readers can select concrete improvements to existing workflows separately from suspected problems and proposed capabilities. Assess keeps each item’s identity through reclassification and archival. Browse displays its recorded category and any submission relationship that affects the reader’s decision. Shared audits stay available when an individual item moves. See the [source change](https://github.com/SaKaNa-Y/skills/commit/acd1c10).

The migration accounted for 122 records across nine projects and verified the destinations of 773 moved files. A read of the installed instructions and project index located four active improvements in the Vite+ example. These checks cover file integrity, navigation and scope selection. They do not measure assessment quality in a fresh agent session.

# Explicit Modifier Skills May Specialize Task Workflows

Co-active Skills remain independent, but some user-selected behaviors need to deliberately specialize another skill's process. We introduce Explicit-only Modifier Skills: when directly invoked, their named specialization governs ordinary process rules while the task skill owns its work and mandatory safety, authorization, external-effect, and human checkpoints remain; this enables behaviors such as Decision Pruning without silently broadening agent authority.

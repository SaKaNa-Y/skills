# Show priority and change risk in the project overview

When a project overview is next updated, its active tables show the recorded priority for each item and the risk of its proposal or patch. The columns preserve who chose a priority and which revision a risk rating covers. A proposed change can still await a risk assessment.

A trial using copies of four project records preserved a suggested P2, an owner-selected P3, a shared patch rating, and an unrated proposal. Separate exercises compared additional assessment and review instructions on two small patches. Both versions found the input regressions and reached the same merge decisions. The existing review guidance was retained.

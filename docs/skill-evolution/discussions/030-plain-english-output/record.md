# Shared English output

All 16 skills now use the external simple-english skill for new or revised English prose. Each consumer declares the loading and preservation contract directly, so setup is not a prerequisite. Setup can also configure a shared policy through agent entrypoints for ordinary tasks. The [architectural decision](../../../adr/0012-share-english-output-requirements.md) explains the dependency and semantic boundaries.

The integration preserves meaning, uncertainty, requirement strength, domain terms and task-required formats. Missing dependency instructions leave affected English delivery pending as a draft while independent work continues. It does not change the requested language or authorize runtime installation.

An initial round loaded the dependency before all 16 final outputs, but two consumers sent English progress text first. The repaired contract explicitly includes progress updates. A second round of 16 fresh bounded writing probes loaded the dependency before post-activation English output. Tool events and output review support these observations; they do not establish universal compliance or end-to-end correctness of each engineering workflow.

Disposable setup checks covered first configuration, shared entrypoints and a fresh repeat with no further changes. Missing-dependency and mixed-language interview cases preserved the pending state and required format. Source reference checks and recovery checks cover the complete candidate tree. Detailed trials and exact recovery patches remain in the local evolution archive. Installed copies and real global client configuration were not changed.

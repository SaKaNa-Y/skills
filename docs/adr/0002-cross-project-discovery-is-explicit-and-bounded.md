# Cross-project Discovery Is Explicit and Bounded

A cross-project discovery skill may deliberately explore beyond an Anchor Project, but it runs only through explicit user selection, searches under finite and evidence-based stopping rules, and ends at a Discovery Report and Exploration Checkpoint rather than implementation. This preserves the repository's User Problem and authorization boundaries while allowing evidence-backed Universal Core, Adapter, and Platform opportunities to be considered; a candidate without a plausible maintenance model cannot be recommended.
